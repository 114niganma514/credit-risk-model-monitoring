5. Glossary & Methodology

TermDescription
PSI (Population Stability Index)Classic risk metric for distribution difference; PSI = sum((actual_share - expected_share) * ln(actual_share / expected_share))
KLD (Kullback-Leibler Divergence)Information-theoretic measure of distribution difference, aka relative entropy; KL(P||Q) = sum P * ln(P/Q)
Covariate ShiftFeature distribution P(X) changes while P(Y|X) stays fixed - the main drift type simulated in this report
Reference / CurrentDevelopment-period distribution (expected) vs post-launch new-data distribution (actual)
Equal-frequency BinningQuantile-based 10 bins with roughly equal shares - the standard practice for PSI
AUC / KSDiscrimination metrics: area under the ROC curve / max gap between good and bad score CDFs

Data source: Give Me Some Credit (provided by FICO, Kaggle competition), 150,000 rows. This report splits "pre/post launch" by row order and injects artificial drift into the current period to demonstrate monitoring capabilities. Thresholds use the industry-standard values 0.10 / 0.25.
